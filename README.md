# Hedef 2027 - 8-C Çalışma ve Takip Asistanı 🎓

Oruç Reis Ortaokulu 8-C sınıfı için özel olarak tasarlanmış, Linux dan Windows uyumlu, terminal tabanlı (CLI) LGS çalışma ve ders takip aracı.

---

## ⚙️ Kurulum Rehberi

Projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz.

### 1. Projeyi İndirme (Git Klonlama)
Terminal (Linux) veya Komut İstemi / PowerShell (Windows) uygulamasını açın ve şu komutu yazın:
```bash
git clone [https://github.com/kullaniciadi/hedef-2027.git](https://github.com/kullaniciadi/hedef-2027.git)
cd hedef-2027
(Not: kullaniciadi kısmını kendi GitHub kullanıcı adınızla değiştirmelisiniz.)

2. Gereksinimleri Yükleme
Arayüz bileşenleri için gerekli olan rich kütüphanesini yükleyin:

Windows için:

Bash
pip install rich
Linux için:

Bash
pip3 install rich
🚀 Çalıştırma
Kurulum tamamlandıktan sonra işletim sisteminize uygun komut ile uygulamayı başlatabilirsiniz:

🪟 Windows Kullanıcıları için:
Bash
python main.py
🐧 Linux Kullanıcıları için:
Bash
python3 main.py
